# Cognifyz Java Tasks 🚀

This repository contains a collection of Java applications built as part of the **Cognifyz** program. The projects are categorized into different levels, progressively focusing on foundational to intermediate Java programming skills such as conditional statements, user input checking, strings, and randomized operations.

## 📂 Project Structure & Tasks Overview

### Level 1

* **Task 1: Temperature Converter (TemperatureConverter.java)**  
  A console-based application that allows users to seamlessly convert temperature values between Celsius and Fahrenheit.

* **Task 2: Palindrome Checker (PallindromeChecker.java)**  
  A utility that takes a word or phrase as input and checks if it is a palindrome, ignoring spaces and capitalization. 

* **Task 3: Student Grade Calculator (StudentGradeCalculator.java)**  
  Calculates the total marks, average percentage, and assigns an alphabetical grade to a student based on marks obtained in 5 subjects.

* **Task 4: Random Password Generator (RandomPasswordGenerator.java)**  
  Generates a highly secure, random password based on user-defined length and character preferences (uppercase, lowercase, numbers, and special characters).

### Level 2 (Upcoming/WIP)

* **Task 1: Tic-Tac-Toe**
* **Task 2: Password Strength Checker**
* **Task 3: File Encryption & Decryption**

## 💻 Prerequisites

To run these applications on your local machine, you will need:

- **Java Development Kit (JDK) 8** or higher installed.

## 🚀 How to Execute the Tasks

Follow these steps to compile and run any of the tasks locally.

### 1. Clone the repository

```bash
git clone <your-github-repo-url>
cd <repository-directory>
```

### 2. Compile the Java Code

Since the Java files are organized into packages, compile them from the root directory referencing the full path.

Example:

```bash
javac CognifyzTasks/Cognifyz/Level1/Task1/TemperatureConverter.java
```

### 3. Run the Application

After successful compilation, use the `java` command along with the fully qualified package name to execute:

```bash
java CognifyzTasks.Cognifyz.Level1.Task1.TemperatureConverter
```

💡 **Note:** To run other tasks, simply replace `Task1` and `TemperatureConverter` with the respective folder and class name you wish to run.

Example:

```bash
java CognifyzTasks.Cognifyz.Level1.Task3.StudentGradeCalculator
```
